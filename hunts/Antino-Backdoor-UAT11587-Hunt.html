Executive Summary

Antino is a Rust Windows backdoor operated by UAT-11587, a China-nexus actor (Talos: high confidence) conducting intelligence collection against government, defense, diplomatic, legislative, think-tank and civil-society targets in Taiwan, India, the Philippines, Cambodia, Pakistan, Thailand, Myanmar and Syria. Talos counted at least 16 affected or targeted institutional environments and about 350 compromised endpoints between September 2025 and July 2026.

Delivery is a spear-phish that clones the Gmail attachment card and links to a Cloudflare Pages HTA or WSF stager, then a five-stage chain (JScript downloader, RC4-decrypted .NET BinaryFormatter gadget chain, TestAssembly.dll in mshta.exe memory, a three-file bundle) that ends with the signed ADK binary GatherOsState.exe sideloading slc.dll. Command and control then runs entirely through Microsoft Graph against attacker-owned Outlook and OneDrive: no conventional C2 server, and the traffic terminates at graph.microsoft.com and login.microsoftonline.com.

Because the C2 destination is a trusted Microsoft endpoint and the loader hosts are Microsoft-signed or Cloudflare-hosted, destination blocking cannot carry this detection. This pack therefore leads with the behavioural chain (script host lineage, sideload host path, Scripted Diagnostics proxying, Run-key persistence, non-browser Graph polling) and uses indicators as a supplement. 13 queries are provided.

Defender priority: hunt Q4, Q6, Q7 and Q11 first (GatherOsState.exe off-path, sideload co-location, sdiagnhost.exe children, Graph lookups from the sideload host), search back to September 2025, and review mail for envelope-sender osc-cdn.com. Treat any GatherOsState.exe outside a Windows Kits path as a likely compromise until proven otherwise.

Hardening: Tiered

Immediate (this week)
  • Block the three actor domains (osc-cdn.com, microsoft-flash.com, wps-cn.com) at DNS, proxy and mail gateway; they are the only prevent rows in the IOC import. MITRE M1031 Network Intrusion Prevention. Authority: Talos recommendation, repeated by CSA. Verify: Resolve-DnsName osc-cdn.com returns NXDOMAIN or the sinkhole.
  • Turn on ASR rules in audit, then block: "Block executable content from email client and webmail" (BE9BA2D9-53EA-4CDC-84E5-9B1EEEE46550) and "Block JavaScript or VBScript from launching downloaded executable content" (D3E037E1-3EB8-44C8-A917-57927947596D). MITRE M1040 Behavior Prevention on Endpoint. Authority: Microsoft Defender ASR rules reference. Verify: Get-MpPreference ASR ids and actions.
  • Change the default handler for .hta, .wsf and .wsh to Notepad so a double-click does not execute them. MITRE M1042 Disable or Remove Feature or Program. Authority: best-practice, no formal benchmark.
  • Hunt back to September 2025 with Q1 to Q13 and review mail for the osc-cdn.com envelope sender.
Near term (1 to 4 weeks, pilot first)
  • Deny mshta.exe for standard users with WDAC or AppLocker (pilot ring, audit mode first). MITRE M1038 Execution Prevention. Authority: CIS Microsoft Windows benchmark application-control guidance and Microsoft recommended block rules. Verify: Get-AppLockerPolicy -Effective -Xml or CQL Q1 returning zero after enforcement.
  • Disable Windows Script Host for users who do not need it (HKLM\SOFTWARE\Microsoft\Windows Script Host\Settings\Enabled = 0). MITRE M1042. Authority: best-practice, no formal benchmark.
  • Restrict where signed Microsoft binaries may run from: publisher rules scoped to Program Files and Windows, so GatherOsState.exe from a user-writable folder cannot execute. MITRE M1038. Authority: Microsoft WDAC guidance.
  • Enforce DMARC (p=quarantine or reject) on your own domains and quarantine inbound mail that passes SPF only on a mismatched envelope sender. MITRE M1054 Software Configuration. Authority: NIST SP 800-177 and CISA email-authentication guidance. The Talos delivery succeeded because the impersonated domain was at p=none.
Strategic (1 to 3 months)
  • Egress control for Graph traffic by process and tenant: allow Graph and Entra login only from sanctioned clients, and evaluate Microsoft Tenant Restrictions v2 at the proxy so authentications to tenants you do not own are refused. ⚠ Verify that TRv2 covers app-only client-credential token requests before relying on it; Microsoft documents it for user and external-identity sign-ins. MITRE M1037 Filter Network Traffic.
  • Detection around identity, process and behaviour, not destination (CSA): document which workloads need Graph, scope application-only Graph permissions with Role Based Access Control for Applications in Exchange Online, and review Entra app registrations on a schedule. MITRE M1018 User Account Management, M1026 Privileged Account Management.
  • Remove mshta.exe and Windows Script Host from endpoints that do not need them once the pilot shows no dependency. MITRE M1042.
