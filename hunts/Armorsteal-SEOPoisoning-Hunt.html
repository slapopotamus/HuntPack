Executive Summary

Armorsteal is a Python-based information stealer, remote access tool and clipboard hijacker that Zscaler Threat Hunting tracked through an SEO poisoning campaign first identified in September 2026 (report published 2026-10-22). Typosquatted sites impersonating the Chocolatey package manager (choclatey[.]org) and the Microsoft Activation Scripts project (massgravel[.]net) ranked in search results for install commands and showed a PowerShell one-liner for the victim to paste into an elevated prompt. The attacker objective is credential, session and cryptocurrency theft: browser data, Discord tokens, wallets, seed phrases, SSH keys and Steam data, plus keylogging, screenshots and wallet-address swapping.

The malware installs a standalone Python 3.11 runtime and Pyarmor-protected modules under C:\Windows\SystemHealth\Update\, persists with scheduled tasks SysCheck2 (user logon, highest privileges) and SysCheckX (system boot, SYSTEM, 45-second delay), and only runs C2 tasks whose RSA-2048 signature verifies against an embedded key. The highest-value defensive angle is behavioral and does not depend on rotating infrastructure: the fake SystemHealth\Update directory, the two task names, and browsers started with --remote-debugging-port=9222.

Defender priority: hunt the fake SystemHealth directory and the SysCheck2 / SysCheckX tasks first (Q4 to Q7), then block the lure and C2 domains. The campaign's two lure sites were reported down by early October 2026, so infrastructure hits are most likely historical: a clean domain sweep does not clear a host.
