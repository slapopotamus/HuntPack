Executive Summary

AuditTeam is a ransomware and extortion group that Kaspersky GReAT (Securelist, 2026-11-18) ties with high confidence to the OpsAgent framework. OpsAgent is a modular implant that Securelist says rivals Cobalt Strike: file management, process injection, privilege escalation, keylogging, screenshots, SOCKS and agent-to-agent pivoting. The campaign began in January 2026 and ran through at least October 2026 against dozens of organizations across at least seven countries and territories. The ransom note is formatted as an audit log and demands an “Audit & Consulting fee” in return for a vulnerability report and non-disclosure of stolen data. The note does not mention encryption, but it is dropped by the cryptor module, so a victim who sees it already has encrypted files.

The intrusion chain Securelist describes: a loader (C in April 2026, .NET in June, Rust in September) unpacks OpsAgent; the implant pulls its C2 address from a public GitHub repository README or from CloudFront subdomains; jobs run in a sacrificial host process (default msiexec.exe, notepad.exe for the keylogger) fed XOR-encrypted shellcode over a named pipe; an AV/EDR killer installs a validly signed Beijing Jiangmin driver (kvcore.sys) to terminate about 220 security processes; and the cryptor stops database and backup services, deletes shadow copies and encrypts with AES-CBC or ChaCha20 under X25519-wrapped per-file keys.

Highest-value defensive angles: the driver drop and its service key (the one step that precedes security-tool loss), the shellcode host processes (msiexec.exe and notepad.exe doing network or no-argument work), and pre-encryption impact commands. Network indicators are perishable: the reported GitHub repository was removed in November 2026 and the latest Rust implants have that feature disabled.

Defender priority: run Q4, Q5 and Q6 now (driver drop). Once the AV/EDR killer runs, endpoint telemetry from that host may stop, so a silent host that was reporting yesterday is itself a finding. Import the section 10 CSV as detect only: this is single-vendor reporting and the driver is a legitimate signed product.

Native Audit-Log Hunts

Checks that need no EDR query language. Sysmon is on the AV/EDR kill list, so absence of Sysmon events from a host that normally reports is itself worth a ticket.

  • Driver and service: Windows System log 7045 (service installed) and Security 4697 for a service whose image path ends in kvcore.sys; Sysmon event 6 (driver loaded) for kvcore.sys with a Beijing Jiangmin signer outside an environment that licenses that product.
  • Files: Sysmon event 11 or an MFT/USN journal search for C:\Users\Public\kv_dbg.log, kvcore.sys in both drivers directories, and syscache.dat under Microsoft\Windows\Caches (ProgramData and per-user AppData\Local), Microsoft\CLR_v4.0, the module directory and the temp path.
  • Injection: Sysmon event 8 (CreateRemoteThread) targeting msiexec.exe or notepad.exe; event 10 with write-memory access to those targets; event 17 and 18 (pipe created, connected) for unusual pipe names created by msiexec.exe or notepad.exe.
  • Impact: Security 4688 with command-line auditing for vssadmin, wmic shadowcopy, wbadmin and bcdedit; System log 7036 and 7040 service stop events for SQL Server, Oracle, MySQL, PostgreSQL, MongoDB, Redis and Veeam services outside a change window; Application log Volume Shadow Copy Service errors.
  • Network: proxy or firewall logs for the two reported CloudFront subdomains and the reported IP; DNS server logs for the same names.
  • Ransom note: search file shares for a new text note formatted as an audit log mentioning an Audit & Consulting fee and a Tor address.

  • Hypervisor-protected code integrity (HVCI) after a driver compatibility survey. Framework: M1050, M1038.
  • Segment database and backup servers and require just-in-time admin access. Framework: M1030 Network Segmentation, M1026 Privileged Account Management.
  • Egress allowlisting for servers so CloudFront and GitHub reach only approved hosts. Framework: M1037, M1021 Restrict Web-Based Content. Marked best-practice: no formal CIS control covers per-server GitHub egress.
