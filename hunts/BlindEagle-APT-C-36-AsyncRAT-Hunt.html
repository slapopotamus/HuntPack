Executive Summary

Blind Eagle (APT-C-36) is running a new phishing wave against Latin America, Colombia a priority, with Portuguese and Spanish lures posing as court notices, fiscalía notices, tutela proceedings and administrative documents. The attachment is an SVG disguised as .xhtml that renders a fake Fiscalía General de la Nación page and builds a password-protected ZIP inside the browser (HTML smuggling, ZipCrypto), so the mail gateway never sees the archive. Inside is a JavaScript dropper posing as “Network Configuration Auditor v2.7.298”, which chains to a VBScript stage (AMSI and ETW bypass, fake “CITACION PENAL, FISCALIA” decoy), Startup-folder persistence, and a PowerShell loader that decodes and runs the final RAT in memory. The RAT is an AsyncRAT fork with DCRat lineage carrying the developer markers Boss/Client77 and Client77. Zenox reports the cluster as Brazilian-operated and as a recent, purpose-built, single-node infrastructure.

Highest-value defensive angle. Atomic indicators are thin: Zenox withholds every full hash and every configuration value, and only two domains and one IP are published. Detection weight therefore sits on behaviour: script hosts launched from a ZIP extraction folder, the SvcConfig<random>.vbs and index_<suffix>.xhtml filename patterns, wscript-to-PowerShell hand-off, and the three network indicators.

Honest scope. Zenox reproduced the chain in a lab and states it could not confirm any real-world compromise. This pack is a hunt for the technique, not a statement that anyone is compromised.

Defender priority. Run Q3 and Q7 first (highest confidence, lowest noise), then Q1, Q2 and Q6. Treat every indicator as detect only: no indicator has two independent sources, and wscript.exe and powershell.exe are stock tools.

Native Audit-Log Hunts

Non-CQL checks. Run N1 to N5 in parallel with the CQL hunts.

  1. N1 Mail gateway and mailbox audit. Search the last 30 days for attachments with extension .xhtml, .xht or .svg on messages with Spanish or Portuguese judicial subjects (tutela, demanda, citación, fiscalía, despacho, constancia, notificação). Note recipients in judicial, public-administration and education units. Message-header authentication passing does not clear a message (S01).
  2. N2 Proxy and DNS logs. Query for crp2026[.]online and the hostname vpfinal142[.]myvnc[.]com. Query firewall logs for 45[.]146[.]81[.]142 and any workstation-to-internet traffic on TCP 4782.
  3. N3 Windows event logs (or Sysmon equivalents). Security 4688 / Sysmon 1 for wscript or cscript with a ZIP-extraction path; Sysmon 11 and 23 for SvcConfig*.vbs and index_*.xhtml; Sysmon 15 (FileCreateStreamHash) or deletion of Zone.Identifier streams; PowerShell 4104 script blocks containing GZipStream together with a custom decoder and Reflection.
  4. N4 Startup folder inventory (read-only; run per host or through your RMM):
Get-ChildItem -Force -ErrorAction SilentlyContinue -Path `
  "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup", `
  "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp", `
  "$env:APPDATA\Microsoft", "C:\Users\Public" |
  Where-Object { $_.Name -match '^(SvcConfig[A-Za-z0-9]{4,12}\.(vbs|lnk)|index_[A-Za-z0-9]{4,12}\.xhtml)$' } |
  Select-Object FullName, Length, CreationTimeUtc, LastWriteTimeUtc
  1. N5 Memory scan of suspect hosts. If a host shows Q3 or Q6 hits, capture memory and string-scan for the developer markers Boss/Client77, Client77 and the class names in section 3. The RAT is not on disk, so a disk scan will find nothing.
