Executive Summary

CLoader Bot is a Windows bot with loader functionality that Seqrite Labs (Manoj Kumar Neelamegam and Rumana Siddiqui, published 2026-11-23) describes being delivered by spear-phishing to organizations and individuals in Thailand. The email carries a .pdf.lha archive named like a purchase order, which holds an obfuscated .pdf.JS JavaScript file. The script drops a standalone LuaJIT interpreter and an obfuscated Lua script into the user's Documents folder and runs the script through that interpreter. The Lua stage contacts an initial C2 IP, then a C2 domain, and downloads a UPX-packed payload into Temp. That payload hides the final bot in its PE resource, decodes it in memory and drops SecurtyHeathService.exe into a random 4-character .tmp folder.

The bot persists with a scheduled task and a Run key masquerading as SecurityHealthAgent, adds Windows Defender exclusions with Add-MpPreference, fetches its C2 configuration from a Pastebin raw URL, keeps a secondary channel to a sytes.net host on TCP 31104, and accepts PSRUN, BYRUN and RUNFILE tasking. Seqrite names no actor, no sector and no link to any other malware family, and this pack asserts none.

Intel limits: Seqrite is the only technical source found. It publishes MD5 hashes only, so every Falcon IOC row ships as detect. The task name and Run key path are not published, and three dropped file names were lost in the page conversion, so those are covered by behavior, not by guessed values.

Highest-value defensive angle: the chain is easy to see by behavior: a script host that launches a binary from Documents (Q1), a .pdf.JS file run by a script host (Q3), Defender exclusions added from PowerShell (Q5) and an executable running from a 4-character .tmp folder (Q7). These do not depend on any perishable IP or hash.

Defender priority: block .lha and script attachments at the mail gateway, enable the ASR rule that blocks JavaScript launching downloaded content, turn on Tamper Protection, then run Q1, Q3 and Q5 over the last 30 days.

Native Audit-Log Hunts

Non-CQL checks for coverage outside endpoint telemetry, or as corroborating pivots.

  1. Email gateway: search inbound mail for attachments ending in .lha or .pdf.lha, and for script files (.js, .jse) inside archives. Look for subjects and bodies with ORDER PO-style purchase order wording sent to Thai recipients, and for Thai-language lure filenames.
  2. Web proxy or secure web gateway: search for requests to pastebin.com/raw/bts1Yn4Z, the raw configuration path Seqrite reports. Any hit means the bot read its configuration. Also search for the two C2 domains and for TCP 31104 to cloaderx.sytes.net.
  3. Firewall or NetFlow: search for connections to the three published IP addresses and to TCP 31104 from workstation subnets.
  4. Windows Defender operational log: review event ID 5007 (configuration changed) for new exclusion entries, and inspect Get-MpPreference exclusions fleet-wide using the audit block in section 10.
  5. Task Scheduler operational log (Microsoft-Windows-TaskScheduler/Operational, event ID 106): look for new tasks whose name contains SecurityHealth and that are not part of the genuine Windows build.
  6. PowerShell logging (event ID 4104): search for Add-MpPreference with an exclusion argument.
