Executive Summary

On 2026-11-24 SafeDep reported two npm packages, clampony (account tinafo6772) and safeclamp3 (account felisox354), that copy the one-function clamp utility and add a preinstall hook. The OSSF malicious-packages repository merged an independent InvisiRisk report for clampony the same day (PR 1830). In clampony 1.0.9 to 1.0.11 the hook downloads a Windows credential stealer from a Pastebin raw path and a calcal.ru raw path on every install. The stealer takes cloud keys, SSH keys, registry tokens, saved FTP and SSH client sessions, shell history and Telegram Desktop session data, uploads them to a Telegram bot, and downloads enterotoxin.exe, a remote-access trojan that logs keystrokes and runs operator tasks.

What is and is not confirmed. The dropper is live and the stealer on Pastebin is complete. The npm package does not yet execute what it downloads: SafeDep and the OSSF report both state that run(filepath) is empty and the downloaded bytes are never written to the temp path. SafeDep adds that stage 2 loads its HTTP client with require('undici'), so it would fail from the temp folder, and the operator would have to change the paste or the load path to make it run. Because the stealer sits on Pastebin, that change needs no new npm release. This pack therefore does not claim stealer execution in the wild. A host that installed clampony 1.0.9 to 1.0.11 reached Pastebin and calcal.ru and exposed its IP address; a host that installed any later version on Windows should be treated as compromised.

Where the value is. Detections are layered by how far the chain got: the install itself (Q1, Q2), the network fetch (Q10), the hidden download-and-run of the RAT (Q3, Q8), the stealer's staging (Q5), and the RAT's persistence and agent (Q4, Q6, Q7, Q11, Q12). Prevent-grade blocks are limited to the three URLs both sources flag; every other indicator is single-sourced and ships as detect.

Defender priority: (1) search lockfiles and node_modules for clampony and safeclamp3 and remove them; (2) enforce the three prevent URLs at the proxy or gateway and alert on any traffic to calcal.ru and 195.123.6.29 (443 and 13599), which are single-source and ship as detect; (3) on any Windows host that installed a version newer than 1.0.11, or that shows the enterotoxin files, tasks or Run value, isolate it, rotate every credential in Section 10, and end other Telegram sessions from a phone.

Native Audit-Log Hunts (non-CQL)

None of these needs a Falcon sensor. Run them on developer machines, build servers and in source control. Values come from SafeDep's detection guidance, adapted to read-only checks.

1. Lockfiles and installed packages

# Repository sweep (POSIX shell or Git Bash)
grep -rnE 'clampony|safeclamp3' --include=package.json --include=package-lock.json --include=yarn.lock --include=pnpm-lock.yaml .
find . -type d \( -name clampony -o -name safeclamp3 \) -path '*node_modules*' 2>/dev/null
# SafeDep scanner
vet scan -D .

2. Windows persistence and agent files (PowerShell, read-only)

Get-ScheduledTask | Where-Object { $_.TaskName -in 'Ensure Updater','StoreUpdateMaintenance','Agent' -and $_.TaskPath -match 'MicrosoftSoftware|WindowsUpdate|Enterotoxin' } | Select-Object TaskPath, TaskName, State
Get-ChildItem "$env:LOCALAPPDATA\Programs\Microsoft Store" -Filter 'MicrosoftStoreUpdaterV*.exe' -ErrorAction SilentlyContinue
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' | Select-Object 'MicrosoftStoreUpdater*'
Get-ChildItem "$env:LOCALAPPDATA\Microsoft\Store\UpdateCache" -Filter 'obj-*.spy' -ErrorAction SilentlyContinue
Get-ChildItem "$env:LOCALAPPDATA\Microsoft\Store\UpdateState\Tasks" -ErrorAction SilentlyContinue
Get-ChildItem "$env:LOCALAPPDATA" -Recurse -Filter 'events.ksp' -ErrorAction SilentlyContinue
Get-ChildItem $env:TEMP -Directory -Filter 'files-staging-*' -ErrorAction SilentlyContinue
Get-ChildItem $env:TEMP -Recurse -Filter 'sysvolume.zip' -ErrorAction SilentlyContinue

3. Hijacked taskbar shortcuts (PowerShell, read-only)

$sh = New-Object -ComObject WScript.Shell
Get-ChildItem "$env:APPDATA\Microsoft\Internet Explorer\Quick Launch\User Pinned\TaskBar" -Filter *.lnk -ErrorAction SilentlyContinue |
  ForEach-Object { $l = $sh.CreateShortcut($_.FullName); [pscustomobject]@{ Name=$_.Name; Target=$l.TargetPath; Args=$l.Arguments } } |
  Where-Object { $_.Target -match 'MicrosoftStoreUpdaterV' -or $_.Args -match '--payload' }
# A hit means the agent rewrote the shortcut. Unpin it and pin the original program again (after isolating the host).

4. Network and logs

  • Firewall, proxy and DNS logs: 195.123.6.29 on ports 443 and 13599; calcal.ru; the nine proxy host:port pairs in Section 10; api.telegram.org from developer hosts that have no business with the Telegram Bot API.
  • Windows Security log 4698 (task created) and 4688 (process creation with command line, if enabled; see Playbook 4); Sysmon event 1, 3, 11 and 13 where deployed.
  • If a host reached Pastebin and calcal.ru only (clampony 1.0.9 to 1.0.11), the IP address was disclosed and stage 2 was staged but, per both sources, not executed.

5. Telegram

If a host may have run the stealer, open Telegram on a phone, go to Settings, Devices and end every other session. The stealer copies the Desktop tdata folder, which lets the attacker open the account elsewhere.
