Executive Summary

Attacker objective: install a full-featured remote access trojan on Windows machines belonging to people who go looking for ChatGPT. The entry point is the new part. A Google sponsored result for the search "chatgpt" led to an attacker-built Custom GPT titled "Plus 5.6" that lives on the genuine chatgpt.com domain and is dressed to look like a new model. Whatever the visitor types, it answers with a "Service Availability Notice" and sends them to a "backup domain", which is a Google Sites page posing as a Cloudflare check. That page is a ClickFix lure: the victim pastes a PowerShell command, and an eight-stage chain follows.

Huntress (O'Halloran and Semon, published 2026-09-28) tied at least 40 incidents to the Google Sites page and confirmed two as having begun at a Custom GPT. OpenAI removed the first GPT by 2026-09-25 and Huntress found a replacement on 2026-09-27 that delivers the identical RAT through a modified wrapper.

The chain is built so every hop hides the next. PowerShell fetches a script from a server written as a decimal number instead of a dotted IP address, defeating dotted-IP rules. The script silently installs an MSI. The MSI drops a genuine, validly signed vendor binary (Canon COTFileReadApp.exe in the first wave, Stardock DeElevate64.exe in the second) into a fake product folder under %LOCALAPPDATA%\Programs\ and launches it. The signed binary loads a patched logging DLL from its own folder, which pulls in malicious helpers. A helper decrypts a loader out of a WAV file whose audio was overwritten with ciphertext (V1) or out of a NuGet package (V2). The loader blinds AMSI, unhooks ntdll, checks for VMs, and unpacks the RAT from monitor.raw, a home-made encrypted archive of 806 files that also holds a persistence script. Persistence is a Run value and a scheduled task with the same name, and the script recreates whichever one you delete.

Attribution and naming: Huntress attributes this to no named actor and gives the RAT no family name. This pack does not coin one. It refers to the Custom GPT ClickFix RAT campaign (Huntress research) and states plainly that the RAT family is unnamed in public reporting.

Highest-value defensive angle: hunt the behaviour, not the names. Huntress itself warns that Canon- and Stardock-keyed detections "will miss the next swap" and that a third installer was already staged. The durable chain is PowerShell to a silent msiexec on a GUID-named MSI in Temp, then a signed app started by msiexec from a fake folder under %LOCALAPPDATA%\Programs\, then a Run value and scheduled task that share a name and come back when deleted.

Defender priority: a hit means a remote operator with screen, camera, microphone and file-search access, not a malware cleanup. When you eradicate, kill the signed host process first, then remove both persistence artefacts; delete either one while the implant runs and it returns within minutes. Treat credentials and sessions on the host as exposed. Q1, Q4 and Q6 are the three highest-confidence hunts.

Hunter notes and deliberate omissions

  • All coverage is one lineage. BleepingComputer, Security Affairs, The Hacker News, CyberSecurityNews and the CSA note all relay the Huntress report. Outlet count is not independent confirmation of the indicators. This is why only one indicator ships at prevent and every hash ships at detect.
  • Prevent posture: exactly one indicator, 96.62.224[.]81, is set to prevent. It appears in the Huntress table, CyberSecurityNews and the CSA note, and it is a bare delivery address with no legitimate use. No hash is at prevent because every hash is carried by Huntress alone.
  • No legitimate binary is blocked. COTFileReadApp.exe and DeElevate64.exe are genuinely signed vendor software, as are msiexec.exe, powershell.exe and GOMCam2024.exe. Their hashes ship at detect with low severity and are triaged on install path.
  • Legitimate platforms are not blocked as domains. chatgpt.com and sites.google.com are legitimate. The GPT and Sites URLs are proxy-log pivots and optional path-level blocks, never Falcon domain IOCs.
  • C2 not recovered. Huntress did not find the C2 address in any file; the RAT resolves it through DNS-over-HTTPS. The CSV carries a labelled REPLACE_WITH_C2_GATE_DOMAIN placeholder rather than an invented value.
  • The attacker command is not reproduced. Its shape (fetch cmdlet, decimal host, numbered script in Temp, bypass flag) is described and hunted in Q1 and Q2.
  • Scope separation from other ClickFix packs. The library carries other ClickFix campaigns. No lure, domain, hash or infrastructure from any of them is used here. What distinguishes this campaign is the Custom GPT entry, the decimal-encoded host, the Canon and Stardock sideload pair, the WAV carrier, monitor.raw and the two named persistence artefacts.
  • Unverified in this pack: the Huntress "Defense Drill" video, figures, and the full IOC table were read as text only; the samples themselves were not analysed independently. The third MSI (UltraFreeISOCreateWizardSolution.msi) was not obtained by Huntress, so no hash exists.

Hardening: Tiered

Controls are ordered by leverage against this chain. It needs five things from the endpoint: a human willing to paste a command, PowerShell with web access, the ability to install an MSI without elevation, permission to run a binary and load DLLs from a per-user folder, and an unmonitored autostart. Remove or watch each one. Where a platform has no formal benchmark entry the control is flagged.

Immediate: deploy this week
  • I1 · Remove the Run dialog (per-user policy) and brief users that no ChatGPT, CAPTCHA or "backup domain" page ever needs them to paste a command. MITRE M1042 (T1204.004) and M1017. Benchmark: CIS Microsoft Windows 11 Enterprise Benchmark, user Start Menu and taskbar settings (confirm the exact recommendation number in your benchmark version). Limit: Huntress describes the command being pasted into a terminal, and this policy does not affect Windows Terminal, so I1 reduces one path only. Playbook P1. Verify with the section 10 audit block.
  • I2 · Turn on PowerShell script block logging. M1047 (T1059.001). Benchmark: CIS Windows benchmark, Administrative Templates, Windows PowerShell. The decoded stage-1 layer is built in memory with a scriptblock, so event 4104 is the one place the real script is recorded. Playbook P3.
  • I3 · Import the IOC CSV and promote the four IOAs in Monitor. M1049 (detection side). Only 96.62.224[.]81 is prevent; see section 10.
  • I4 · Alert on the pasted-command shape at the web gateway. Add a proxy rule for any HTTP request whose host is a bare integer, and log (do not yet block) requests to chatgpt.com/g/ and sites.google.com/view/. M1021 (T1566.002, T1105). best-practice, no formal benchmark
Near term: 1 to 4 weeks, pilot first
  • N1 · Restrict per-user MSI installs. # Prerequisites: local administrator on the CONTAINED host (Falcon network containment on; use Real Time Response
#   to run it). Capture evidence first (section 14, C2). Run in the affected user's context for the HKCU steps.
