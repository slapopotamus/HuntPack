Executive Summary

A DPRK-linked actor (the Graphalgo cluster, publicly attributed to Lazarus by ReversingLabs since May 2025) has expanded its fake-recruiter supply-chain campaign beyond npm and PyPI into the HashiCorp Terraform Registry and the Go module ecosystem — the first publicly documented case of malware distributed through Terraform providers. Two trojanized Terraform providers (gocommunity-io/dockerd, and kreuzwenker/docker, a one-character typosquat of the legitimate kreuzwerker/docker provider with 56M downloads) and two malicious Go modules (gocommunity.io/orderedbtree, gogets.dev/btreex) carry a Go RAT that is functionally a Go port of the existing Graphalgo npm/PyPI malware, sharing C2 infrastructure and a threat-actor public key with the JavaScript samples.

The attacker's objective is direct: reach a developer or DevOps workstation via a fake Web3 job-interview lure, get the victim to run a coding task that pulls in the trojanized package, and land a targeted, self-deleting RAT that is gated to fire only under narrow, attacker-chosen conditions (a specific SHA256 hash of Terraform variables, or a crafted numeric input) — explicitly to frustrate researchers who find the backend payload without its matching front end. The RAT's dual C2 (an Ethereum smart contract on the Arbitrum Sepolia testnet, and an attacker-controlled Slack workspace polled via conversations.history) is a sophisticated, low-noise dead-drop design built to survive endpoint remediation: because commands are pulled, not pushed, an attacker retains reachability even after the malicious package itself is removed.

The highest-value defensive angle is not trying to detect the AES-encrypted payload or the blockchain traffic content (both are opaque to EDR by design) — it is catching the narrow, low-FP process-lineage signature of a Terraform provider or Go module spawning a detached go run ., and locking down provider/module installation to a vetted mirror before a targeted developer or CI/CD runner is ever exposed. Terraform providers routinely run with direct access to cloud IAM credentials, so a single successful infection on a DevOps host is a materially worse outcome than the same RAT on a typical developer laptop.

Defender priority: developer and CI/CD-runner workstations that can execute terraform init/terraform apply or go get/go run against untrusted registries are the primary exposure. Lock provider/module installation to an internal mirror (Section 13, Playbook A) before relying on detection alone — the activation gate on this malware is specifically designed to evade sandbox and default-tenant detection.

Web Hunter decisions

  • Prompt-injection scan: all four fetched sources were scanned for text directed at an AI agent (instructions to run commands, fetch other URLs, change output paths, claim authorization, etc.). None was found in any of the four sources. No source was dropped from citation for this reason.
  • Provenance discipline: every atomic indicator shipped in this pack (Section 4, Section 10) was copied verbatim from one of the four saved snapshots and mechanically re-verified against them before publish. No indicator was invented.
  • v0.2 revision — infrastructure de-duplication (this pass): the TraderTraitor typosquatted Terraform-registry domains (registry.hashicorp-aws.com, registry.hashicorp-aws.io, registry.hashicorp-terraform.io) were removed entirely after check_coverage.py --check-pack flagged them as shared infrastructure already owned by the published TraderTraitor-FLATROOF-ROOFDECK-Hunt.html pack. That is correct: those domains are TraderTraitor's own C2/distribution infrastructure, a distinct malware family (FLATROOF/ROOFDECK, Rust, macOS), not Graphalgo's. The query built on them (former Q9) was rewritten around a Graphalgo-owned indicator instead (see Section 8, Q9). The SentinelOne source is kept for narrative "Terraform Registry as an emerging attack surface" context only — it ships no IOCs here.
  • Same reasoning applied to the GHAPPIER/PolinRider overlap: on review, the IP 193.247.144[.]38 and the trailing byte marker 68656c6c6f6970626f742121 ("helloipbot!!") are CloudSEK's GHAPPIER-loader indicators (via The Hacker News), overlapping with a distinct, long-running cluster called PolinRider — delivered through a different incident (the compromised @dforge-core/dforge-mcp npm package), not the Graphalgo Terraform/Go RAT. check_coverage.py did not flag these two specifically (the published PolinRider-Hunt.html currently ships them only as REPLACE_WITH_ placeholders, not live values), but the underlying attribution problem is identical, so they were removed from this pack on the same reasoning rather than waiting for the gate to catch a future collision once PolinRider-Hunt.html is populated. Hunters tracking that overlap should use PolinRider-Hunt.html.
  • Single-source discipline: Aikido is the sole source for the campaign's payload hashes, C2 workspace names, and the threat-actor public key. Per standing IOC-governance policy, every indicator in this pack ships at Detect, never Prevent, until an independent second source corroborates it or a 14-day clean bake completes in your own tenant (see Section 11).
  • No atomic IOC was converted to a placeholder — every remaining indicator in this pack is independently re-confirmed against the live sources and is exclusively Graphalgo's own infrastructure.

Native Audit-Log Hunts

These checks require no Falcon query — they read the developer's own project files and are cheap enough to run fleet-wide via RTR or an MDM/RMM script before or alongside the CQL hunts.

Go dependency audit (Linux/macOS/Windows)

grep -RIn "gocommunity\.io\|gogets\.dev" $(find / -name "go.sum" -o -name "go.mod" 2>/dev/null) 2>/dev/null
# PowerShell equivalent:
Get-ChildItem -Recurse -Include go.sum,go.mod -ErrorAction SilentlyContinue |
  Select-String -Pattern "gocommunity\.io|gogets\.dev"

Terraform lock-file audit

grep -RIn "kreuzwenker\|gocommunity-io" \
  $(find / -name ".terraform.lock.hcl" 2>/dev/null) 2>/dev/null

GitHub organization / vendoring audit

Check whether any internal repo forks, vendors, or references code from the threat-actor-controlled GitHub identities: gocommunity-io, go-pack-tech, kreuzwenker, gogets-dev, victormmpp, markcary3, steveb082, go-community-admin.

Slack workspace visibility — an honest limit

This campaign's Slack C2 uses attacker-owned workspaces (portfolio-devs.slack.com, portfolio-testers.slack.com, mediumstar.slack.com) reachable from any host with outbound HTTPS. There is no native audit-log visibility into this from your own Slack tenant — your Slack admin console cannot see traffic to someone else's workspace. Rely on DNS/proxy/CASB egress logs (Q4, Q9) instead. Your own Slack Enterprise Grid App Manager audit is still worth running as a separate hygiene check, for any bot/app token with a conversations.history or channels:history scope your security team did not provision.

CrowdStrike LogScale CQL Hunt Queries

Pick your tenant's cloud first — every "Open in Falcon" button below uses this selection.
Q1 · Terraform Provider Plugin Execution From User-Writable Cache Paths
CONF HIGHFP LOWCOST LOW

Looks for: A terraform-provider-* binary executing from a user-writable Terraform plugin cache path (.terraform.d/plugins, AppData\terraform.d\plugins) or downloaded directly from registry.terraform.io -- the exact vector Aikido documents for gocommunity-io/dockerd and kreuzwenker/docker.

// HUNT: Terraform Provider Plugin Execution From User-Writable Cache Paths
// MITRE: T1195.002, T1204.002
// CONF: high
// FP: low
// COST: low
// REQUIRES: ProcessRollup2/SyntheticProcessRollup2 on Windows, Linux and macOS developer + CI hosts
// FALSE POSITIVES: an internal Terraform provider mirror published under the same terraform-provider-* naming convention
// LOOKBACK: 7d (set window in the Falcon time picker, not in-query)
#event_simpleName=/ProcessRollup2|SyntheticProcessRollup2/
| FileName = /^terraform-provider-.*$/i
| (CommandLine = *.terraform.d*plugins* or CommandLine = *terraform.d\plugins* or CommandLine = *registry.terraform.io*)
| table([ComputerName, UserName, FileName, ParentBaseFileName, CommandLine, SHA256HashData, @timestamp])
| sort(@timestamp, order=desc)
Q2 · Detached 'go run .' Execution Spawned By a Terraform Provider Process
CONF HIGHFP LOWCOST LOW

Looks for: A terraform-provider-* process spawning 'go' with a 'go run .' command line -- the documented second-stage launch mechanism (detached go run . executing the AES-decrypted Go RAT source).

// HUNT: Detached 'go run .' Execution Spawned By a Terraform Provider Process
// MITRE: T1195.002, T1027, T1140
// CONF: high
// FP: low
// COST: low
// REQUIRES: ProcessRollup2/SyntheticProcessRollup2 with parent-child lineage (ParentBaseFileName)
// FALSE POSITIVES: provider SDK developers legitimately running 'go run .' inside a provider's own source tree -- rare on a compiled, installed provider's parent process
// LOOKBACK: 7d (set window in the Falcon time picker, not in-query)
#event_simpleName=/ProcessRollup2|SyntheticProcessRollup2/
| ParentBaseFileName = /^terraform-provider-.*$/i
| (FileName = /^go(\.exe)?$/i or CommandLine = *go run .*)
| table([ComputerName, UserName, ParentBaseFileName, FileName, CommandLine, SHA256HashData, @timestamp])
| sort(@timestamp, order=desc)

Q4 · Non-Slack-Client Process Polling api.slack.com
CONF MEDIUMFP HIGHCOST LOW

Looks for: A process other than a known Slack/browser client resolving slack.com -- a coarse proxy for the malware's bot-token conversations.history check-in and 10-second poll loop.
