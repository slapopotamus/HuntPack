Executive Summary

TGR-STA-0049 (also tracked as Ink Dragon, Earth Alux and REF7707) is a cyberespionage group that Unit 42 reports has targeted Southeast Asian government entities since at least July 2025. Its newest tooling is two custom backdoors: PerfectPioneer RAT (Go, first seen July 2025, six variants) and the modular C++ KUKURAT (March 2026). Both talk to their C2 over HTTP/3 on QUIC (UDP 443), with HTTP/2 fallback, which many TCP-centric inspection stacks never see.

The reported chain starts with web shells on unpatched Exchange and web servers (ASPXSpy, Godzilla, Bysunue.aspx, Suo5), with phishing using decoy PDFs and lookalike government domains as the second route. Payloads run as DLL side-loads of a modified legitimate executable carrying XOR-encrypted shellcode, as decoy installers, or as executables dressed up as PDFs. The actor then dumps LSASS through comsvcs.dll by ordinal, runs DCSync, spreads with PsExec, WMI, WinRM and malicious domain logon scripts, and grants itself FullAccess to every Exchange mailbox.

This pack ships 15 CQL hunts, 82 atomic indicators from the Unit 42 report (71 SHA256, 9 domains, 2 IPs, all detect-only), hardening with rollback for each deployable step, and a containment runbook. Telemetry that endpoint events cannot see (QUIC URL paths, named pipes, DCSync, Startup shortcuts) is routed to native hunts in section 7 and flagged as gaps in section 15.

Defender priority: hunt Exchange and IIS servers first (Q1, Q5, Q6), run the LSASS and credential queries (Q3, Q4) on domain controllers and servers, then sweep DNS, IP and hash indicators (Q10, Q11, Q14) over 90 days. Restrict or log outbound UDP 443 from servers.

Playbook 1: Log and then block outbound UDP 443 from servers

Prerequisites: Local administrator; test on a pilot server group first. This stops QUIC for browsers on that host, which fall back to TCP, so confirm no approved app requires QUIC.
Reboot required: No
Rollback: Remove-NetFirewallRule -DisplayName "HP Block outbound QUIC UDP 443"

# 1. Check current state
Get-NetFirewallRule -DisplayName "HP Block outbound QUIC UDP 443" -ErrorAction SilentlyContinue
# 2. Create the rule (use -Action Allow with logging first if you only want visibility)
New-NetFirewallRule -DisplayName "HP Block outbound QUIC UDP 443" -Direction Outbound -Protocol UDP -RemotePort 443 -Action Block -Profile Any
# 3. Verify
Get-NetFirewallRule -DisplayName "HP Block outbound QUIC UDP 443" | Get-NetFirewallPortFilter

Playbook 2: LSA protection and the LSASS credential-theft ASR rule

Prerequisites: Local administrator; Windows 10/11 or Server 2016+; Defender Antivirus active for the ASR rule. Test for incompatible security drivers or plug-ins in audit mode first.

Playbook 3: Audit Exchange impersonation and FullAccess grants (read-only, then optional removal)

Prerequisites: Exchange Management Shell with Organization Management rights. The listing is read-only. Removal changes access for the named accounts, so confirm each with its owner first.
Reboot required: No
