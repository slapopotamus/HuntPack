Executive Summary

Checkmarx documented MALFEX, a single-operator npm supply-chain campaign active since August 2023. Twelve packages were published and eight carry malware, delivering three payload paths to Windows hosts. As of 2026-10-01, function-flag, function-color and cdn-img-fetch were still installable, and function-flag and function-color carried no advisory. Lifetime downloads total 40,767, of which 37,419 are function-flag.

Path 1 (Overlord RAT): tlxbnhd, tldriver and mxdriver run npm preinstall and postinstall scripts that fetch a file served as a PNG from api.imghippo.com. It is really an IExpress self-extracting archive holding a signed AutoIt3 interpreter and an encrypted script, which decrypts to the Overlord RAT and hollows TapiUnattend.exe. Persistence is the scheduled task \Maiden running AutoIt3.exe h.a3x every five minutes from %LOCALAPPDATA%\ScopeSmart Technologies Inc\.

Path 2 (movinlike): native-runner to img-to-native to cdn-img-fetch runs on require() with no install hook, so --ignore-scripts does not stop it. A banner image from the cavecrew/proj GitHub repository hides an AES-encrypted Go downloader that fetches the Node.js stealer from 104.234.65.75. Path 3 (function-flag): a postinstall runs node example.js, which calls an ASCII-art function with the font Bloody and triggers a hidden download to %APPDATA%\node.exe.

This pack hunts behavior and operator infrastructure: AutoIt running .a3x scripts, the \Maiden task, TapiUnattend.exe execution, node_runtime_helper, executables running from the root of %APPDATA%, and the named hosts and IPs. Stock tools (AutoIt3.exe, node.exe, TapiUnattend.exe, explorer.exe) are detect-only throughout.

Defender priority: search every lockfile, registry proxy log and developer endpoint for the eight package names now (Section 7 and Playbook A), run Q1 to Q8 across Windows hosts, and null-route 104.234.65.75. If any of the packages ran on a Windows host, treat that host as compromised and rotate Discord, browser-saved and wallet credentials from a clean system.

CrowdStrike LogScale CQL Hunt Queries

Pick your tenant's cloud first — every "Open in Falcon" button below uses this selection.
Q1 · AutoIt3 executing an .a3x script (Overlord loader and \Maiden task)
CONF HIGHFP MEDIUMCOST LOW

Looks for: AutoIt3.exe started with an .a3x argument, the exact form of the Overlord persistence command (AutoIt3.exe h.a3x) and the loader run. FP: admins who legitimately run compiled AutoIt scripts. AutoIt3.exe is a signed legitimate tool, so this is detect-only.

// HUNT: AutoIt3.exe running an .a3x script (MALFEX Overlord loader)
// MITRE: T1059, T1053.005, T1055.012
// CONF: high
// FP: medium
// COST: low
// REQUIRES: ProcessRollup2 on Windows
// FALSE POSITIVES: IT automation that runs .a3x scripts
// TUNING: scope to unmanaged paths by keeping ImageFileName matching ScopeSmart, or allowlist your own AutoIt deployment folder; any AutoIt3.exe under a user profile on a developer host deserves review
#event_simpleName=/^(ProcessRollup2|SyntheticProcessRollup2)$/
| event_platform=Win
| FileName=/^AutoIt3(_x64)?\.exe$/i
| CommandLine=/\.a3x/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, ImageFileName, CommandLine, SHA256HashData])
Q2 · schtasks creating the Maiden task
CONF HIGHFP LOWCOST LOW

Looks for: schtasks.exe creating or changing a task whose name contains Maiden, or whose action references an .a3x script or the ScopeSmart folder.

Q7 · Executables run from the root of %APPDATA% (function-flag payloads)
CONF MEDIUMFP MEDIUMCOST LOW

Looks for: node.exe, svchost.exe, nocry.exe or malfex.exe running directly from AppData\Roaming with no subfolder, the location function-flag writes its payload. node.exe and svchost.exe are legitimate names; the abnormal path is the signal. FP: portable Node.js installs unpacked into Roaming.

// HUNT: payload executables at the root of AppData Roaming (MALFEX function-flag)
// MITRE: T1105, T1036.005
// CONF: medium
// FP: medium
// COST: low
// REQUIRES: ProcessRollup2 on Windows
// FALSE POSITIVES: portable Node.js copy placed in Roaming by a developer
// TUNING: svchost.exe, nocry.exe and malfex.exe in this location are near-certain malicious; for node.exe exclude hosts where your standard dev image places Node there, and review the parent process
#event_simpleName=/^(ProcessRollup2|SyntheticProcessRollup2)$/
| event_platform=Win
| FileName=/^(node|svchost|nocry|malfex)\.exe$/i
| ImageFileName=/\\AppData\\Roaming\\(node|svchost|nocry|malfex)\.exe$/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, ImageFileName, CommandLine, SHA256HashData])

CrowdStrike Custom IOA Recommendations

Q1 to Q5 are behavior-pinned and survive infrastructure rotation, so they are IOA candidates. Q7 and Q10 stay Investigate-only until baselined. No IOA blocks a stock tool by name or hash.

IOA-1 · AutoIt3 runs an .a3x script HIGH PRIORITY

Pattern: Process Creation, image name AutoIt3.exe, command line contains .a3x. Deployment: detect mode first. Exclusions: your sanctioned AutoIt automation folder. Never set to prevent, since AutoIt3.exe is a signed legitimate tool.

IOA-2 · Maiden scheduled task creation

Pattern: Process Creation, image schtasks.exe, command line contains Maiden. Deployment: detect mode. Exclusions: none identified.

IOA-3 · gldriver_pre or node_runtime_helper execution

Pattern: Process Creation, image name matches gldriver_pre_core, gldriver_pre_asset or node_runtime_helper. Deployment: detect, then promote to prevent after one clean week since the names are specific to this chain. Exclusions: none identified.

# Playbook B: disable lifecycle scripts and use lockfile-only installs on CI agents
