Executive Summary

Trellix (published 2026-10-26) describes a Korean-language spear-phishing campaign that poses as a FedEx tax invoice and delivers a previously undocumented variant of the Sirius Backdoor, a Microsoft Visual C++ remote-access backdoor. A ZIP carries a visually blank PDF whose /OpenAction and /Launch objects run hidden, encoded PowerShell. Each stage decrypts and reflectively loads the next in memory, the last stage patches ETW to blind endpoint sensors, then hollows msbuild.exe or svchost.exe with Early Bird APC injection to run the backdoor.

The operator gets hidden-desktop (HVNC) control, an embedded SOCKS5 proxy, webcam and microphone capture, a keylogger, a regex-driven cryptocurrency clipboard hijacker and Chromium credential harvesting. Persistence is unusually deep: Run key, scheduled task, Startup items, a logon script hijack, default-profile poisoning and a provisioning package that survives a full Windows reset.

Defensive angle: almost nothing lands on disk, and the stock binaries (svchost.exe, msbuild.exe, powershell.exe) are the cover. The highest-value detections are parent-context hunts: a PDF reader starting PowerShell (Q1), the exact stager flag set (Q2) and a hollowing host with the wrong parent (Q3). Atomic indicators are few and single-origin, so every one ships as detect.

Defender priority: enable the Adobe Reader child-process ASR rule in audit mode this week and run Q1 and Q3 across 30 days. If a host hits, reimage rather than reset: the .ppkg persistence is built to survive Push-Button Reset.

  • Review Defender exclusions on all hosts; Sirius adds its own. M1047. Playbook P5.
Near term (1 to 4 weeks, pilot first)
  • PowerShell Constrained Language Mode through WDAC or AppLocker, which blocks the dynamic .NET and reflection the stager uses. M1038 Execution Prevention; Trellix recommendation. Pilot in audit mode: it breaks admin scripts.
  • Acrobat Protected View and launch-action restrictions through the product's enterprise policy. M1042 Disable or Remove Feature. Best practice; confirm the exact keys for your Acrobat build. Playbook P4.
  • Restrict who can write C:\Recovery\Customizations, C:\Windows\Setup\Scripts and the Default profile hive to SYSTEM and TrustedInstaller. M1022 Restrict File and Directory Permissions. Best practice; check imaging tools first.
Strategic (1 to 3 months)
  • WDAC allow-listing so a copy of svchost.exe or a DLL in a user path cannot run. M1038 and M1045 Code Signing.
  • Remove PDF readers' ability to launch files by standardising on a reader without launch actions, or sandboxing it. M1042 and M1048 Application Isolation.
  • Reimage standard: include a clean-out of the Recovery Customizations folder in the build so a reset cannot restore implant packages. Best practice, no formal benchmark.
