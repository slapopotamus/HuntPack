Executive Summary

Star Blizzard, a Russia-nexus threat actor subordinate to FSB Centre 18 (also tracked as COLDRIVER, Callisto, SEABORGIUM, and TA446), has run at least 13 large-scale phishing campaigns since January 2026 against more than 100 organizations, mostly in the United States and United Kingdom, tied to Ukraine policy: NGOs, think tanks, government bodies, and financial institutions. Since March 2026 the group has broadened targeting beyond Ukraine specifically.

The group's objective is durable, low-friction access. Its RedFlick delivery technique needs only a single user interaction, opening an LNK file disguised as a PDF inside a password-protected archive, a meaningful reduction in friction from the group's 2025 ClickFix delivery chains. RedFlick has shipped in three documented variants across 2026 (January VHDX, April three-scheduled-task, July PDF steganography), all of which converge on installing the CosmicPulse backdoor (internal name YESROBOT) via Windows scheduled tasks and a Python 3.8 bootstrapper.

The single highest-value defensive angle in this pack is behavioral, not atomic: all three 2026 delivery variants register one of three exact scheduled task names ("Internet Quality Test Connection", "Network Configuration Manager", "System Health Monitor"). That artifact is corroborated across all four sources reviewed for this pack and is the flagship detection (Section 8, Hunt H3).

Defender priority: deploy the H3 scheduled-task hunt and the four ASR rules in Section 12 (Tier 1) this week. They cover all three RedFlick variants at their common persistence step, regardless of which delivery chain a target organization actually receives.

Hunt Brief & Attack Chain

Three delivery variants, one common endpoint

VariantPeriodChain
VHDX chainJan 2026Password-protected ZIP → VHDX containing an LNK disguised as a PDF → LNK runs conhost.exe → hidden cmd.exe executes a BAT script → BAT opens a decoy PDF and invokes ssh.exe (PermitLocalCommand=yes, LocalCommand=cmd.exe) to download an MSI → MSI creates a scheduled task running control.exe (Control_RunDLL via Shell32.dll) to fetch the CosmicPulse CPL.
Three-task persistenceApr 2026MSI installs three scheduled tasks: "Internet Quality Test Connection" (registration / dynamic DLL execution via WebDAV), "Network Configuration Manager" (WebDAV enablement helper), "System Health Monitor" (CosmicPulse downloader execution). Tasks use control.exe and WebDAV UNC paths (\\host@SSL\...) for HTTP-based C2.
PDF steganographyJul 2026Password-protected RAR nested in a ZIP → LNK → conhost.exe + curl.exe download a decoy PDF from actor infrastructure → PowerShell searches the PDF for the magic header "cAB," and extracts a 208-byte Base64 payload → decoded payload downloads an MSI creating two further scheduled tasks.

CosmicPulse execution

Whichever variant delivers it, the CPL downloader fetches two ZIP files: a Python 3.8 64-bit package plus a bootstrapper script, and the encrypted CosmicPulse payload (internal name YESROBOT; the downloader component is also referred to as NOROBOT or BAITSWITCH). The bootstrapper decrypts the payload with AES-ECB using a key stored in the registry at HKEY_CURRENT_USER\Software\Classes\.mollis, then runs python.exe from a user-writable path.

CrowdStrike LogScale CQL Hunt Queries

Pick your tenant's cloud first — every "Open in Falcon" button below uses this selection.
H1 · VHDX/LNK Chain — Hidden BAT Execution via conhost.exe
CONF MEDIUMFP MEDIUMCOST LOW

Looks for: conhost.exe spawning a hidden cmd.exe that runs a .bat script (Jan 2026 variant). FP: some RMM/packaging tools follow this same parent/child shape; narrow with a confirmed RMM inventory before excluding.

// HUNT H1: Star Blizzard RedFlick - VHDX/LNK Chain - Hidden BAT Execution via conhost.exe -> cmd.exe
// HYPOTHESIS: If the January 2026 RedFlick VHDX variant is active, conhost.exe (spawned by the
// malicious LNK) launches a hidden cmd.exe that executes a .bat script referencing a decoy PDF
// and a follow-on SSH download.
// MITRE: T1059.003 (Windows Command Shell), T1564 (Hide Artifacts), T1204.002 (User Execution)
// CONF: Medium - behavioral pattern (parent/child + .bat reference), no atomic IOC
// FP: Medium - conhost.exe legitimately spawns cmd.exe constantly; narrowing to a .bat reference
// reduces but does not eliminate legitimate hits from install scripts and some RMM tooling.
// COST: Low - indexed event type + ParentBaseFileName exact match before regex
// GAP NOTE: no Falcon event for VHDX mount/attach is confirmed in the sourced intel; this query
// covers only the conhost->cmd->bat stage.
// LOOKBACK: 7d

#event_simpleName = /ProcessRollup2|SyntheticProcessRollup2/
| ParentBaseFileName = /^conhost\.exe$/i
| FileName = /^cmd\.exe$/i
| CommandLine = /\.bat/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, CommandLine])
| sort(@timestamp, order=desc)

// TUNING: exclude known-good RMM/packaging tools confirmed in your environment to spawn cmd.exe
// via conhost.exe with a .bat reference; verify against your RMM inventory before excluding, no
// blind FileName-level exclusion is safe to ship.
H2 · SSH Client Abuse for MSI Download (PermitLocalCommand)
CONF HIGHFP LOWCOST LOW

Looks for: ssh.exe invoked with PermitLocalCommand=yes and a LocalCommand referencing cmd.exe. FP: very few legitimate Windows workflows use this option combination.

// HUNT H2: Star Blizzard RedFlick - SSH Client Abuse for MSI Download (PermitLocalCommand)
// HYPOTHESIS: If the January 2026 RedFlick chain is active, ssh.exe is invoked with
// PermitLocalCommand=yes and a LocalCommand referencing cmd.exe, used to trigger a local
// download of the CosmicPulse MSI installer via the SSH client rather than an SSH session.
// MITRE: T1105 (Ingress Tool Transfer), T1059.003 (Windows Command Shell)
// CONF: High - this exact SSH client option combination on Windows is rarely legitimate
// FP: Low - very few legitimate Windows workflows invoke OpenSSH client with PermitLocalCommand
// COST: Low - indexed event type + FileName exact match before CommandLine regex
// LOOKBACK: 7d

#event_simpleName = /ProcessRollup2|SyntheticProcessRollup2/
| FileName = /^ssh\.exe$/i
| CommandLine = /PermitLocalCommand=yes/i
| CommandLine = /LocalCommand=.*cmd\.exe/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, CommandLine])
| sort(@timestamp, order=desc)

// TUNING: none required at Low FP. If internal DevOps/sysadmin tooling legitimately uses
// PermitLocalCommand for automation, add an explicit UserName or ComputerName allowlist
// exclusion rather than broadening the CommandLine match.
H3 · Scheduled Task Persistence (Exact Task Names) — FLAGSHIP
CONF HIGHFP LOWCOST LOW

Looks for: schtasks.exe registering one of the three exact RedFlick task names, used across all three 2026 variants. This is the flagship detection for this pack; see the alert package in Section 16.

// HUNT H3: Star Blizzard RedFlick - Scheduled Task Persistence (Exact Task Names)
// HYPOTHESIS: If RedFlick's persistence mechanism fired, an MSI custom action or the Task
// Scheduler registers one of three exact task names used across all three 2026 delivery
// variants: "Internet Quality Test Connection", "Network Configuration Manager",
// "System Health Monitor".
// MITRE: T1053.005 (Scheduled Task)
// CONF: High - the three task names are highly specific and corroborated across all 4 sources
// FP: Low - these exact task names are not standard Windows or common third-party task names
// COST: Low - FileName exact match before CommandLine regex
// COVERAGE NOTE: detects task registration via schtasks.exe (used by MSI custom actions and
// installers). If your tenant's sensor policy also surfaces a native scheduled-task-registered
// telemetry event with a TaskName field, mirror this filter against it too - confirm the event
// is available in your tenant before relying on it; it is not assumed here.
// LOOKBACK: 7d

#event_simpleName = /ProcessRollup2|SyntheticProcessRollup2/
| FileName = /^schtasks\.exe$/i
| CommandLine = /\/create/i
| CommandLine = /(Internet Quality Test Connection|Network Configuration Manager|System Health Monitor)/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, CommandLine])
| sort(@timestamp, order=desc)

// TUNING: none required - task names are distinctive enough that no baseline exclusion is
// expected. If a false positive appears, verify against your organization's own IT asset
// naming conventions before excluding.
H4 · CosmicPulse CPL Execution via control.exe
CONF MEDIUMFP MEDIUMCOST LOW

Looks for: control.exe invoking Control_RunDLL against a CPL staged in a user-writable directory. FP: legitimate CPL registration from AppData/Temp/ProgramData is uncommon but not impossible; baseline 7-14 days before promoting.

// HUNT H4: Star Blizzard RedFlick - CosmicPulse CPL Execution via control.exe
// HYPOTHESIS: If CosmicPulse deployment completed, control.exe is invoked with a Control_RunDLL
// call against a CPL (Control Panel applet) DLL staged in a user-writable directory
// (AppData/Temp/ProgramData) rather than a standard system CPL location.
// MITRE: T1218 (System Binary Proxy Execution - Control Panel)
// CONF: Medium - control.exe abuse is a known LOLBin technique; the user-writable-path
// constraint is the distinguishing signal for this campaign
// FP: Medium - legitimate software occasionally registers CPL applets, though rarely from
// AppData/Temp/ProgramData
// COST: Low - FileName exact match before CommandLine regex
// LOOKBACK: 7d

#event_simpleName = /ProcessRollup2|SyntheticProcessRollup2/
| FileName = /^control\.exe$/i
| CommandLine = /Control_RunDLL/i
| CommandLine = /(AppData|\\Temp\\|ProgramData)/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, CommandLine])
| sort(@timestamp, order=desc)

// TUNING: exclude known-good software update/installer tools only if confirmed in your
// environment to legitimately register CPL applets from user-writable paths; verify with a
// 7-14 day Detect-only baseline before promoting.
H5 · WebDAV-based C2 (April 2026 Three-Task Variant)
CONF MEDIUMFP MEDIUMCOST LOW

Looks for: a command line referencing a WebDAV UNC path of the form \\host@SSL\... FP: legitimate enterprise WebDAV-backed file shares (e.g. SharePoint Online) can trigger this; add a domain exclusion once confirmed.

// HUNT H5: Star Blizzard RedFlick - WebDAV-based C2 (April 2026 Three-Task Variant)
// HYPOTHESIS: If the April 2026 three-scheduled-task variant is active, a task action (typically
// via rundll32.exe, cmd.exe or msiexec.exe) accesses a WebDAV UNC path of the form \\host@SSL\...
// to reach the actor's HTTP(S)-based C2 over the WebDAV redirector, avoiding a literal http(s)://
// URL in the command line.
// MITRE: T1071.001 (Web Protocols), T1105 (Ingress Tool Transfer)
// CONF: Medium - the "@SSL" WebDAV UNC marker is a specific and unusual command-line pattern
// FP: Medium - WebDAV UNC access is occasionally legitimate (e.g. SharePoint Online mapped over
// WebDAV) so a positive hit still needs host/destination triage
// COST: Low - event type + CommandLine regex on an anchored literal token
// LOOKBACK: 7d

#event_simpleName = /ProcessRollup2|SyntheticProcessRollup2/
| CommandLine = /\\\\[A-Za-z0-9.\-]+@SSL\\/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, CommandLine])
| sort(@timestamp, order=desc)

// TUNING: if your organization uses legitimate WebDAV-backed enterprise file shares (e.g. a
// tenant SharePoint Online domain mapped over WebDAV), add an explicit domain exclusion once
// confirmed, rather than dropping the @SSL match entirely.
H6 · PDF Steganography Extraction (July 2026 Variant)
CONF MEDIUMFP LOWCOST LOW

Looks for: a PowerShell process with the literal "cAB," marker in its command line, the July variant's steganography extraction step.

// HUNT H6: Star Blizzard RedFlick - PDF Steganography Extraction (July 2026 Variant)
// HYPOTHESIS: If the July 2026 RedFlick variant is active, a PowerShell process reads a
// downloaded decoy PDF and searches it for the magic marker "cAB," to locate and extract a
// 208-byte Base64-encoded payload, which is then decoded and executed to retrieve an MSI.
// MITRE: T1059.001 (PowerShell), T1027 (Obfuscated Files or Information)
// CONF: Medium - the literal "cAB," marker in a PowerShell command line is a distinctive
// artifact specific to this campaign's steganography scheme
// FP: Low - "cAB," as a literal string inside PowerShell CommandLine is not expected in
// legitimate administration scripts
// COST: Low - event type + FileName exact match before CommandLine regex
// COVERAGE NOTE: matches the marker in process CommandLine telemetry. If your tenant separately
// ingests PowerShell Script Block Logging as its own event type, mirror this filter there too

// LOOKBACK: 7d

#event_simpleName = /ProcessRollup2|SyntheticProcessRollup2/
| FileName = /^powershell(\.exe)?$/i
| CommandLine = /cAB,/i
| table([@timestamp, aid, ComputerName, UserName, ParentBaseFileName, FileName, CommandLine])
| sort(@timestamp, order=desc)

// TUNING: none required - "cAB," is a low-collision literal string. If paired with heavy
// internal PDF-processing automation that coincidentally uses this byte sequence, narrow with
// a ParentBaseFileName constraint matching the documented conhost.exe/curl.exe parent chain.

Custom IOA Recommendations

Three behavioral Custom IOA rules complement the CQL hunts above with real-time prevention potential. All start in Detect mode; promote to Block only after a 14-day canary run with a confirmed false-positive rate under 5%.

IOA-1 · RedFlick Scheduled Task Persistence

Rule Group: Persistence — Scheduled Tasks · Action: Detect · Severity: High · MITRE: T1053.005

Image Filename: .*\schtasks\.exe$
Command Line: .*(Internet Quality Test Connection|Network Configuration Manager|System Health Monitor).*
Description: Detects schtasks.exe registering one of the three exact scheduled task names used
by Star Blizzard's RedFlick technique to persist and deploy CosmicPulse.
FP Tuning: none expected - task names are not used by standard Windows or common third-party
software.

IOA-2 · CosmicPulse CPL Launch via control.exe

Rule Group: LOLBIN Abuse · Action: Detect · Severity: Medium · MITRE: T1218

Image Filename: .*\control\.exe$
Command Line: .*Control_RunDLL.*(AppData|Temp|ProgramData).*
Description: Detects control.exe launching a Control Panel applet (CPL) staged in a
user-writable directory, consistent with CosmicPulse CPL-based execution.
FP Tuning: Medium - validate for 14 days in Detect mode before considering promotion;
legitimate CPL registration from user-writable paths is uncommon but not impossible.

IOA-3 · SSH Client PermitLocalCommand Abuse

Rule Group: LOLBIN Abuse · Action: Detect · Severity: High · MITRE: T1105

Image Filename: .*\ssh\.exe$
Command Line: .*PermitLocalCommand=yes.*LocalCommand=.*cmd\.exe.*
Description: Detects OpenSSH client invoked with PermitLocalCommand=yes and a LocalCommand
referencing cmd.exe, the mechanism RedFlick's January 2026 variant uses to trigger a local
MSI download without an interactive SSH session.
FP Tuning: Low - very few legitimate Windows workflows use this SSH client option combination.
