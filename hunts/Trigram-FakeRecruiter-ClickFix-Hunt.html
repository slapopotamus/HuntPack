Executive Summary

Trigram is Stormshield's name for a large, industrialized social-engineering campaign that sends fake recruiter emails, conference invitations and package-tracking lures to get developers to paste and run a command in their own terminal. Stormshield counts about 50 impersonated AI and blockchain brands. The end state is an infostealer plus a persistent remote-access agent that takes browser passwords and cookies, keychains, crypto wallets, SSH keys and .env files on Windows, macOS and Linux (SafeDep).

The novel part is the clipboard swap. The lure page first shows a harmless command that only POSTs a nonce, then fakes an error ("Operation timeout. Please try again. Nonce Refreshed."). From that moment the Copy button and Ctrl+C are hijacked: the clipboard receives a different command, ending in a newline so it executes the instant it is pasted. What the victim sees is not what runs, so a user's description of the command is unreliable evidence and shell history is the ground truth.

The behavioral surface is unusually rich and does not depend on perishable infrastructure: curl -ks writing a file then executing it, setsid -f or a Perl double-fork detach, a hidden wscript //B relaunch, Unblock-File, a portable node-v20.18.1 running install_guard.js, the deepfake_guard.* and NVDG_* kit names, and a .vscode/tasks.json that runs on folder open. This pack ships 19 CQL hunts, nine prevent-posture indicators confirmed by two independent vendors, and 215 further detect-posture indicators.

Attribution is a reported assessment. Stormshield assesses with high confidence that Trigram continues the UNK_DeadDrop cluster that Proofpoint has tracked since April 2026 and Proofpoint rates very likely North Korea-aligned. SafeDep says the technique matches Contagious Interview but that the match "does not prove who the operators are." This pack does not assert state attribution.

Scope: developer workstations (Windows, macOS, Linux) and the repositories, IDEs and package builds they touch. OverLord is an open-source RAT framework and therefore shared tooling; this pack carries only the indicators that the sources tie to the Trigram delivery chain and does not import indicators from other OverLord campaigns.

Defender priority: (1) search shell and PowerShell history for verify_w, verify_m, curl -ks and install_guard on developer hosts, not user recollection; (2) turn on terminal paste protection and stop IDEs auto-running tasks.json; (3) run Q2, Q3, Q7, Q9 and Q10 as scheduled detections; (4) import the CSV in section 10.
