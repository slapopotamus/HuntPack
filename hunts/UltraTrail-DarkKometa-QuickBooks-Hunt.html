Executive Summary

Attacker objective. Infoblox followed a tech-support scam that told victims to install the commercial remote-access tool UltraViewer to the bulk-mailer UltraMailer, then to chanret[.]com, the default tracking domain UltraMailer uses and the tracker for a long-running QuickBooks phishing campaign. That campaign uses more than 350 QuickBooks-lookalike domains, most registered at Dynadot between 2026-06-29 and 2026-07-05, and sends victims to call a scam number to give up QuickBooks credentials. Separately, Infoblox found trojanized installers that bundle an authentic copy of each product with a RAT: an UltraMailer build carrying njRAT and an UltraViewer build carrying DarkKometa (detected as Win32.Comet.A).

Scope and attribution caveat. Infoblox states it found no evidence that the UltraViewer or UltraMailer developers took part in the scams or the malware. It also does not state that the trojanized installers and the QuickBooks phishing operator are one and the same actor; they are linked through shared tooling and registrant research, not proven common control. This pack therefore hunts two related surfaces and labels the evidence for each. It ships only indicators from the Infoblox report. The report also cites third-party Silver Fox research; that is a different campaign covered by a separate published pack and nothing from it is imported here.

Legitimate software. ultraviewer[.]net and ultramailer[.]org are the real vendor sites and a clean UltraViewer or UltraMailer binary is a real product. Those ship as detect-only inventory, never as block entries. The C:\ProgramData\Synaptics\Synaptics.exe touchpad-driver masquerade is a shared technique seen across unrelated malware, not a shared-campaign attribution.

Highest-value defensive angle. (1) Find the two trojanized installers by hash and name and the Synaptics.exe masquerade in ProgramData. (2) Find lookups of the tracking and lookalike domains, which show who opened a phishing mail. (3) Inventory UltraViewer and UltraMailer so unsanctioned remote-access software is visible; Infoblox advises restricting it where there is no business need.

Defender priority: run Q1, Q2 and Q3 now, then Q5. Treat any host that ran either installer as fully compromised (a RAT gives the operator hands-on control) and rotate credentials typed on it. Do not block the vendor domains or the legitimate tools on this evidence.

Native Audit-Log Hunts

7.1 Mail gateway: tracking pixel

Search message bodies and headers for: track.chanret.com
Pixel URL shape: http://track.chanret.com/images/<campaign directory>/<Base64 of recipient address>.jpg
Decode the final path element from Base64 to recover which recipient address was targeted.

Per the report the image is 1x1 and its filename is the recipient's address in Base64. Reversible encoding, not encryption. A message containing it is a delivered phishing mail even if no endpoint resolved the name.

7.2 Mail gateway: call-back numbers

Search message bodies for the digit strings 8058358090 and 8056991139 (ignore punctuation and spacing).

Infoblox lists these two 805 area code numbers as observed. The source text contains invisible characters inside the numbers, so search on digits with separators stripped. They are scam call-back numbers, not endpoint indicators, and numbers are cheap to rotate.

7.3 Proxy and DNS resolver logs

Hostnames to search: chanret.com, track.chanret.com, qbcares.com, smtracking.qbcares.com, smtracking.healthclub951.swp23.com
Pivot: other hostnames that CNAME to the swp23.com tracker (do not treat the swp23.com apex alone as malicious)

7.4 Windows host: installation audit (read-only)

Get-ChildItem 'C:\ProgramData\Synaptics' -Force -ErrorAction SilentlyContinue | Get-FileHash -Algorithm SHA256
Get-ItemProperty 'HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*','HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*' -ErrorAction SilentlyContinue | Where-Object { $_.DisplayName -match '^Ultra(Viewer|Mailer)' } | Select-Object DisplayName, DisplayVersion, Publisher

Compare any Synaptics.exe hash with the genuine driver in your fleet and with Section 4.

7.5 Registrar view

Infoblox reports most lookalike domains were registered at Dynadot between 2026-06-29 and 2026-07-05. If you run domain-monitoring, search new registrations in that window for QuickBooks-themed names; no other lookalike is published in the saved source.
